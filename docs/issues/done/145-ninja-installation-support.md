# Issue #145: Ninja Build System Installation Support

## Overview

Add Ninja build system as an installable package in ptx-installer. Ninja is a small, fast build system designed to have its input files generated by higher-level build systems (CMake, Meson, GN). It is widely used in large-scale C/C++ projects (Chrome, LLVM, Android).

## Motivation

- Ninja is a fundamental build tool for CMake and Meson-based projects
- Required by many C/C++ development workflows
- Simple single-binary distribution makes it ideal for ptx-installer
- Already available via GitHub releases as platform-specific zip archives
- Complements existing development tools in Portunix ecosystem

## Requirements

### Functional Requirements

- [ ] FR-1: Install Ninja via `portunix install ninja` command
- [ ] FR-2: Support direct download from GitHub releases (zip archive)
- [ ] FR-3: Support package manager variants (apt, dnf, chocolatey, pacman)
- [ ] FR-4: Cross-platform support (Linux x64/ARM64, Windows x64)
- [ ] FR-5: Post-installation verification via `ninja --version`

### Non-Functional Requirements

- [ ] NFR-1: Follow existing ptx-installer package definition pattern
- [ ] NFR-2: Auto-discovery by registry (no manual index updates)

## Technical Design

### Package Definition

Create file: `src/helpers/ptx-installer/assets/packages/ninja.json`

Pattern: Similar to `act.json` / `protoc.json` (simple zip archive extraction with single binary)

### Installation Methods

| Platform | Method | Package/URL |
| -------- | ------ | ----------- |
| Linux | Direct download (zip) | `ninja-linux.zip` from GitHub releases |
| Linux | APT | `ninja-build` |
| Linux | DNF/YUM | `ninja-build` |
| Linux | Pacman | `ninja` |
| Windows | Direct download (zip) | `ninja-win.zip` from GitHub releases |
| Windows | Chocolatey | `ninja` |
| Windows | WinGet | TBD |

### Download URLs

Source: `https://github.com/ninja-build/ninja/releases`

URL pattern:

```text
https://github.com/ninja-build/ninja/releases/download/v{version}/ninja-linux.zip
https://github.com/ninja-build/ninja/releases/download/v{version}/ninja-win.zip
https://github.com/ninja-build/ninja/releases/download/v{version}/ninja-mac.zip
```

### Key Technical Details

- **Current version**: 1.13.2 (as of November 2025)
- **License**: Apache-2.0
- **Binary size**: ~200KB (single self-contained binary)
- **No dependencies**: Static binary, no runtime dependencies
- **Extraction**: zip archive containing single `ninja` (or `ninja.exe`) binary
- **Target path (Linux)**: `/usr/local/bin/ninja`
- **Target path (Windows)**: Portunix managed directory or `C:\Program Files\ninja\`

### Verification

```bash
ninja --version
# Expected output: 1.13.2
```

## Implementation Scope

### Files to Modify

None required - registry auto-discovers packages from `assets/packages/` directory.

## Acceptance Criteria

1. `portunix install ninja` successfully installs Ninja on Linux (direct download)
2. `portunix install ninja --variant apt` installs via APT on Debian/Ubuntu
3. `portunix install ninja` successfully installs Ninja on Windows (direct download)
4. `portunix install ninja --variant chocolatey` installs via Chocolatey on Windows
5. `ninja --version` returns expected version after installation
6. Package appears in `portunix install --list` output
7. Installation tested in clean container environment

## Testing

All installation testing MUST be performed in containers per project methodology:

```bash
# Linux testing
portunix container run --image ubuntu:22.04
# inside container:
./portunix install ninja
ninja --version

# Variant testing
./portunix install ninja --variant apt
```
