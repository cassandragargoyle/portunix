# Issue #152: Plugin Create Missing go.mod

## Summary

`portunix plugin create` generates a Go plugin template that cannot be built because `go.mod` (and `go.sum`) are missing. The generated `main.go` imports `google.golang.org/grpc` but there is no module definition, so `go build` fails immediately.

## Current Behavior

```bash
$ portunix plugin create my-plugin --author "Test" --description "Test plugin"
✅ Plugin template created at: ./my-plugin

Next steps:
1. cd my-plugin
2. Edit plugin.json to configure your plugin
3. Implement your plugin in main.go
4. Build: go build -o my-plugin
5. Install: portunix plugin install .

$ cd my-plugin && go build -o my-plugin
go: go.mod file not found in current directory or any parent directory; see 'go help modules'
```

## Expected Behavior

The generated template should include a valid `go.mod` file so that `go build` works out of the box (or at least after `go mod tidy`).

Expected generated files:

```text
my-plugin/
├── go.mod          # <-- MISSING
├── go.sum          # <-- MISSING (generated by go mod tidy)
├── main.go
├── plugin.json
├── README.md
├── examples/
├── proto/
└── src/
```

Expected `go.mod` content:

```go
module my-plugin

go 1.24

require (
    google.golang.org/grpc v1.x.x
)
```

## Additional Observations

1. **Empty directories**: `examples/`, `proto/`, `src/` are created empty — consider either populating them with placeholder files or not creating them until needed
2. **main.go has commented-out import**: The gRPC service registration is commented out (`// pb.RegisterPluginServiceServer`), but the `google.golang.org/grpc` import is active and will fail without `go.mod`
3. **No .gitignore**: The template does not include a `.gitignore` for the Go binary

## Steps to Reproduce

```bash
portunix plugin create test-plugin --author "Test" --description "Test"
cd test-plugin
go build -o test-plugin
# ERROR: go.mod file not found
```
